# LevelChess ♞

A mobile-first chess game where the player beats an AI level by level.

## Current version
- 20 unlockable levels
- Legal chess moves powered by chess.js
- Increasing AI difficulty
- Check/checkmate/draw detection
- Hint button
- Sound effects
- Progress saved on the device
- Installable PWA structure for Android

## Play
Open `index.html` through a web server or publish this repository with GitHub Pages.

## Goal
This repository is being developed step by step toward an Android/Play Store-ready game.
